Video Moodle FFHS

Apri un’attività Moodle e avvia il video. I file rilevati possono essere scaricati usando la sessione di questo browser.

Per i player su altri domini puoi autorizzare l’accesso HTTPS. Il codice considera soltanto le richieste nelle schede Moodle FFHS, mai YouTube. Nessun dato viene inviato a servizi esterni.

    I file finiscono in Download → FFHS_Moodle. Importali nell’archivio dall’applicazione. Un download può fallire se il server richiede un player o una sessione particolare: controlla i download del browser.
