# Download nella versione 0.5

La scelta è l'alternativa 1: **Moodle Buddy per i documenti e FetchV per i video**, usando il browser
normale già autenticato. L'app raccoglie e organizza i risultati locali. Le estensioni restano separate.

L'esportatore API conserva struttura, testi, obiettivi, attività e file esposti dal servizio Moodle.
Non può garantire che le API espongano ogni contenuto visibile nel browser.

Moodle Buddy può scaricare file singoli, gerarchie corso/sezione e ZIP di cartelle. L'app copia i
file selezionati, estrae gli ZIP sicuri e collega i materiali alle attività. Abbinamento automatico
solo per nomi esatti univoci; l'utente può scegliere esplicitamente la destinazione.

FetchV gestisce i download video nel browser. L'app importa il risultato finale nell'attività
scelta. YouTube resta un link. DRM, restrizioni del server e formati non supportati restano limiti reali.

Non si recuperano quiz nascosti, non si avviano tentativi e non si modificano contenuti Moodle.
I libri soltanto citati nel Modulplan non diventano automaticamente file scaricabili. Un file
importato non certifica la completezza del corso.

Per le copie reali raccolte apri `download_estensioni.md`. Leggi `elementi_mancanti.md` insieme
a quei rapporti: descrive la via API. Verifica regole e condizioni FFHS prima di caricare materiali
didattici su servizi AI esterni.
